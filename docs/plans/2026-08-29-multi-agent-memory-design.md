# Multi-Agent Memory 公开版设计

## 目标与边界

公开版提供一个**宿主无关**的本地共享记忆 Skill + CLI，可安装到 Codex 等宿主，也可被其他编码代理直接调用。数据保存在项目内 `.ai-memory-hub`，继续兼容既有的 Markdown 目录和历史命令。首版不依赖云服务、数据库、向量检索或账号体系，避免增加安装成本和隐私风险。

## 组件与数据流

宿主 Skill 识别共享记忆场景并选择读写动作；无依赖 Python CLI 负责校验、锁、原子写入、检索和索引；Markdown 目录是唯一事实来源。读操作不加锁，写操作使用库级排他锁。任务状态按任务和代理拆分，避免多个代理互相覆盖。`remember` 先进入 inbox，长期记忆与 Wiki 仍可由人或代理审阅后整理。

## 错误与恢复

非法路径段、重复归档、未初始化目录和锁超时都返回非零退出码；JSON 模式提供稳定错误结构。临时文件与目标文件位于同一目录，确保原子替换。健康检查只读扫描目录、UTF-8 编码和陈旧锁，不自动修复或重写旧数据。

## 验证

单元测试覆盖初始化、旧参数兼容、字段保留、全文检索、上下文生成、路径穿越防护、并发写入、归档与 JSON 输出。另用真实旧记忆库执行只读兼容测试。插件清单和 Skill 使用官方随附校验器验证，GitHub Actions 在 Windows、Linux 和 macOS 上运行测试。
