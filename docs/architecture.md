# 架构说明

插件分为三个稳定边界：Codex Skill 负责决定何时读写共享记忆；Python 命令行负责参数校验、并发控制和输出；`.ai-memory-hub` 只保存普通 Markdown。代理框架与存储格式因此互不绑定，其他工具可以直接调用命令行，也可以只读 Markdown。

写路径统一经过库级排他锁。内容先写入目标目录的临时文件，刷新到磁盘后再原子替换，避免进程中断留下半个文件。锁文件包含进程号和创建时间，超过两分钟后允许恢复。每次受控写入都会重建轻量索引；正文文件不会在索引过程中被改写。

全文检索是确定性的本地词项计分，不使用远程嵌入模型。这样不会泄露记忆，也没有网络或模型费用。首版刻意不加入向量数据库、后台服务、自动同步和账户体系；后续如需 MCP，只需把现有命令行或 `MemoryHub` 类包装为工具，不必迁移数据。
